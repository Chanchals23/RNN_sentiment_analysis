# RNN Sentiment Analysis - IMDB Movie Reviews

A sentiment analysis project that classifies IMDB movie reviews as positive or negative using a Recurrent Neural Network (RNN) built with PyTorch.

## Workflow

- Cleaned text (removed duplicates, URLs, HTML tags, punctuation)
- Removed stopwords and applied stemming using NLTK
- Converted text to features using TF-IDF Vectorization
- Built and trained an RNN model in PyTorch
- Evaluated model accuracy on a test set

- ## Dataset
- 
[IMDB Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)
